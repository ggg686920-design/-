# نص تسليم لأي AI

أريد تطوير تطبيق كيبورد نسمة الموجود في هذا المستودع، وليس إنشاء تطبيق بديل.

1. اقرأ `AGENTS.md` و`HANDOFF.md` أولاً، وافحص الملفات والفرع الحالي قبل اقتراح التعديلات. المواصفات في `docs/SPEC.md` هي أهداف، وليست ميزات منفذة.
2. السورس المستعاد موجود في `app/src/` والمشروع قابل للبناء. لا تطلب السورس مرة ثانية ولا تعيد فك الـAPK أو بناء تطبيق بديل. اقرأ `docs/RECOVERY.md` لمعرفة أصل الكود وحدود الاختبارات.
3. حافظ على اسم التطبيق و`applicationId` والبيانات والميزات الحالية. نفّذ أصغر تغيير صحيح، ولا تصرف على أدوات أو ميزات خارج المطلوب.
4. استثنِ كلمات المرور والحقول الحساسة من الاقتراحات والتعلّم والحافظة والتسجيل وAI. لا تضف إرسالاً خارجياً أو مفاتيح API ضمن التطبيق.
5. سلّم السورس المحدث داخل المستودع، وحدّث `HANDOFF.md` و`CHANGELOG.md`. وثّق أوامر البناء والاختبارات التي نفذتها فعلاً، وما لم تختبره.
6. إذا بنيت APK، سلّمه مع السورس وطريقة إعادة بنائه. زد رقم الإصدار عند إصدار نسخة، ووضّح توقيعها وإمكانية تثبيتها كتحديث. لا تولّد مفتاحاً بديلاً بصمت، ولا ترفع مفاتيح أو كلمات مرور إلى GitHub.

المطلوب في هذا التحديث: **[اكتب ميزة أو إصلاحاً واحداً هنا]**.

أريد شرح النتيجة بالعربي باختصار: شنو تغيّر، شنو اختُبر، شنو ناقص، ورابط التعديلات.
