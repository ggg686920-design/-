# نسمة | Nasma Keyboard

كيبورد Android عربي/إنجليزي. هذا المستودع هو المرجع المستمر لتطويره مع أدوات AI مختلفة.

> **الحالة الحالية: مشروع Android قابل للبناء، مستعاد من APK الأصلي ومكتمل بملفات Gradle والاختبارات. إصدار التطوير `1.0.1-recovered` يحافظ على اسم التطبيق ومعرّفه وواجهته الأساسية. هذا سورس مستعاد ومنظّف، وليس الملفات الأصلية حرفياً. مفتاح التوقيع الأصلي غير متوفر، ولم يُجرَ اختبار تشغيل على هاتف أو محاكي بعد.**

## بناء المشروع

افتح المجلد في Android Studio، أو استخدم JDK 17 مع Android SDK 35 وBuild Tools 35.0.0:

```sh
bash ./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

على Windows استخدم `gradlew.bat` بدل `bash ./gradlew`. لا تحتاج مفتاح API أو خدمة خارجية لبناء التطبيق أو استخدامه. تنزيل أدوات البناء والمكتبات يحتاج الإنترنت أول مرة.

الناتج: `app/build/outputs/apk/debug/app-debug.apk`. هو إصدار اختبار بتوقيع debug، وليس تحديثاً بتوقيع التطبيق الأصلي. أمر `bash ./gradlew :app:assembleRelease` يبني نسخة release **غير موقّعة**، تحتاج توقيعاً قبل التثبيت.

## طريقة التطوير بدون ضياع الشغل

1. أعطِ الـAI رابط المستودع وميزة أو إصلاحاً محدداً. اطلب قراءة `AGENTS.md` و`HANDOFF.md` أولاً؛ مو كل أداة تقرأهما تلقائياً.
2. اشتغل على فرع صغير من آخر نسخة. لا تجعل أدوات مختلفة تطوّر نسخاً منفصلة غير متزامنة.
3. اطلب توثيق التعديلات والاختبارات والقيود، مع تحديث السورس في GitHub. الـAPK وحده ليس تسليماً كافياً.
4. بعد نجاح البناء والاختبار، استلم APK للتجربة وZIP للسورس أو رابط الإصدار. احتفظ بإمكانية الرجوع للإصدار السابق.

## الموجود فعلياً

- كيبورد عربي/إنجليزي، أرقام ورموز، صفحة حركات وحروف إضافية، Shift وCaps Lock، حذف متواصل وأزرار إدخال حسب الحقل.
- شاشة تفعيل واختيار الكيبورد وتجربة الكتابة، وألوان فاتحة/داكنة حسب النظام للكيبورد.
- كود IME والواجهة المستعادان بـJava، وسياسة حقول جديدة واختباراتها بـKotlin. البنية جاهزة للتطوير الجديد بـKotlin بدون إعادة كتابة شاملة.
- لا توجد اقتراحات أو تصحيح تلقائي أو GIF أو حافظة أو AI بعد. التطبيق لا يطلب الإنترنت ولا يخزن النصوص؛ يحفظ اختيار اللغة فقط.

## ما يحتاج استكمال

اختبار IME على أندرويد أولاً، ثم تحسين الأساسيات والاقتراحات تدريجياً حسب الخطة. **لا حاجة لطلب السورس مرة ثانية؛ اشتغل على `app/src/`.** لو حصلنا لاحقاً على المصدر الأصلي، نقارنه بدل استبدال العمل تلقائياً. مفتاح التوقيع الأصلي يبقى مطلوباً فقط لاستمرار التحديثات فوق النسخة الأصلية، وليس لتطوير وبناء هذا المشروع.

## التحقق المتاح حالياً

```sh
python3 tools/inspect_apk.py artifacts/original/nasma-keyboard.apk
```

يقرأ الأمر بيانات الملف وManifest ويفحص سلامة ZIP فقط. فحص الأرشيف منفصل عن workflow البناء الذي يبني debug وrelease غير موقّع ويشغّل اختبارات JVM وlint. نواتج الاختبار متاحة من تبويب Actions بعد نجاح التشغيل. لا يُعتبر نجاح البناء اختباراً فعلياً للكيبورد على هاتف.

المستودع عام حالياً. لا ترفع نصوص المستخدمين أو سجل الحافظة أو بيانات الدخول. لا توجد رخصة مفتوحة المصدر مختارة؛ كون المستودع عاماً لا يعني منح رخصة تلقائياً.
