# نسمة | Nasma Keyboard

كيبورد Android عربي/إنجليزي. هذا المستودع هو المرجع المستمر لتطويره مع أدوات AI مختلفة.

> **الحالة الحالية: أرشيف APK وتوثيق فقط. السورس الأصلي وملفات Gradle ومفتاح التوقيع غير متوفرة بعد. لا يمكن بناء التطبيق من هذا المستودع حالياً. لم تُنفّذ الميزات الجديدة ولم يُختبر التطبيق على جهاز Android هنا.**

## طريقة التطوير بدون ضياع الشغل

1. أعطِ الـAI رابط المستودع وميزة أو إصلاحاً محدداً. اطلب قراءة `AGENTS.md` و`HANDOFF.md` أولاً؛ مو كل أداة تقرأهما تلقائياً.
2. اشتغل على فرع صغير من آخر نسخة. لا تجعل أدوات مختلفة تطوّر نسخاً منفصلة غير متزامنة.
3. اطلب توثيق التعديلات والاختبارات والقيود، مع تحديث السورس في GitHub. الـAPK وحده ليس تسليماً كافياً.
4. بعد نجاح البناء والاختبار، استلم APK للتجربة وZIP للسورس أو رابط الإصدار. احتفظ بإمكانية الرجوع للإصدار السابق.

## المطلوب الآن

اطلب مشروع Android Studio الكامل من الأداة التي أنشأت APK: السورس، الموارد، القواميس، ملفات Gradle والـWrapper وإصدارات أدوات البناء. لا ترفع مفاتيح توقيع أو كلمات مرور.

إذا تعذّر الحصول على المصدر، يجب الاتفاق على استعادة مشروع من APK أو إعادة بناء موثّقة مرة واحدة. لا نغيّر هوية التطبيق أو ننشئ تطبيقاً بديلاً بصمت. استعادة الكود لا تستعيد مفتاح التوقيع؛ من دونه قد يتطلب تثبيت نسخة معدّلة حذف الحالية وفقد بياناتها.

## التحقق المتاح حالياً

```sh
python3 tools/inspect_apk.py artifacts/original/nasma-keyboard.apk
```

يقرأ الأمر بيانات الملف وManifest ويفحص سلامة ZIP. لا يشغّل التطبيق، ولا يتحقق من توقيعه تشفيرياً، ولا يثبت خلوّه من مشاكل الأمان. فحص CI هنا يحمي سلامة الأرشيف فقط، وليس اختباراً لبناء Android.

المستودع عام حالياً. لا ترفع نصوص المستخدمين أو سجل الحافظة أو بيانات الدخول. لا توجد رخصة مفتوحة المصدر مختارة؛ كون المستودع عاماً لا يعني منح رخصة تلقائياً.
